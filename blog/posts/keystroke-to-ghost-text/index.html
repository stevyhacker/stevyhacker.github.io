Keystroke to ghost text

How LokalBot's autocomplete gets from a keystroke to a suggestion, and where a hosted model could help without anyone waiting for it.

Published Oct 06, 2026 AI · Engineering
Back to blog Open the explainer full screen ↘

LokalBot suggests the next few words as you type in most apps, using a small model that runs on the Mac. This is a design note from early October: how a suggestion gets from a keystroke to the screen in about 140 ms, what hosted models added when they ran on the same prompts, and a proposal for using the cloud only where nobody has to wait for it.

The best hosted model got the next word right 2.7 points more often, but it took about three and a half times as long as the local one. So in the proposal the local model stays in charge, and the cloud only extends a suggestion that is already on screen, or fills in during a pause.
