Nedavno sam saznao za jednu super akciju na Github-u za studente pa sam želio da je podjelim sa drugima i ukažem na to za šta sve može biti korisna. GitHub student developer pack je skup servisa koji će vam omogućiti da nesmetano radite na svojim projektima besplatno dok god traju vaše studije. Izdvojio bih da su tu uključeni i besplatni .me domen na godinu dana, 50$ kredita na Digital Ocean hosting servisu kao i Micro nalog na Github-u sa kojim možete hostovati do 5 privatnih repozitorijuma.

Da bi dobili sve to jedino što je potrebno da uradite jeste da verifikujete svoj status kao studenta, ja sam to uradio tako što sam poslao sliku svog indeksa a drugi način je da se registrujete pomoću email adrese koja je izdata od strane ustanove u kojoj studirate. Sam proces verifikacije zna da potraje ali naravno vrijedi čekati, u mom slučaju posle desetak dana dobio sam pristup kompletnom paketu. Prihvatanjem ponude za svaki servis dobijate uputstvo kako da ga aktivirate, za neke se to radi putem kupon koda dok druge koriste vaš GitHub nalog.

Za aktivaciju i detaljan pregled svega ponuđenog posjetite sledeći link https://education.github.com/pack

Evo kompletne liste servisa:

  • Atom — A hackable text editor for the 21st Century
  • Bitnami — Install cloud applications in a single click
  • Crowdflower — Crowdsourcing and data enrichment platform
  • DigitalOcean — Simple cloud hosting, built for developers
  • DNSimple — Simple DNS management with one-click services and a robust API
  • GitHub — Powerful collaboration, code review, and code management, includes 5 private repositories.
  • HackHands — Live programming help available 24/7
  • Namecheap — Domain name registration and SSL certificates
  • Orchestrate — Unified search, time-series, geolocation, graph database and API
  • SendGrid — Email infrastructure as a service
  • Stripe — Web and mobile payments, built for developers
  • Travis CI — Continuous integration platform for open source and private projects
